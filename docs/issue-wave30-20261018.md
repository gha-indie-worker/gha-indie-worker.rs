# Owned NdArray ABI proof obligations — draft 2026-10-18

Issue #9: canonical `NdArray<T>` storage shared by tensor/ML/numeric libraries.

## Representation
- Owned contiguous backing storage has an explicit allocation owner, element type, base pointer, rank, shape, strides, offset and generation/lease.
- Shape-product multiplication is checked before allocating or computing byte extents, including 0-sized axes and values close to integer overflow.
- Views are non-owning; mutable overlapping/strided aliasing is denied without an exclusive borrow proof. A view cannot outlive its owner or cross an actor ownership boundary.
- Row-major vs column-major layout, alignment and numeric endian representation are ABI decisions, not implied by the host interpreter.
- For actor state, persistent instance data lives only in `state { ... }`; access through trusted `handle_state` / `using` read-write loans.

## Negative vectors
1. Shape `[2^62, 8]` rejects before multiplication/allocation overflow.
2. Shape `[2,3]` + 5-byte f64 backing rejects exact extent mismatch.
3. A mutable slice overlaps another live mutable slice; second loan rejects.
4. View after owner move/drop fails before first load.
5. Zero-length dimension does not dereference an empty buffer.
6. Strided transpose validates extent and stride bounds; no pointer overflow.
7. Cross-actor message copy/move/read-only share preserves lifetime and prohibits mutable alias.

**Status:** ABI acceptance design only; implementation and compiler-backed LLVM/native proof pending.
